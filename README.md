# DS_HW01

Data Structures (Spring 2026) - Homework Assignment 1.

This repository contains the assignment skeleton, local test runner, and sample tests used to validate your implementation.

## What you are expected to implement

Implement the required behavior of `SegmentationResort` in:

- `SegmentationResort26b1.cpp`

The required API and function signatures are defined in:

- `SegmentationResort26b1.h`

For the full task requirements, constraints, and expected complexity guarantees, use:

- `DS_wet1_spring_2026.pdf`

## Repository contents

- `README.md` - this guide.
- `SegmentationResort26b1.h` - class interface and required public API.
- `SegmentationResort26b1.cpp` - implementation file to complete.
- `main26b1.cpp` - command-based driver used for testing your implementation.

- `DS_wet1_spring_2026.pdf` - official assignment specification.

## Build and run tests

### 1) Extract tests

```bash
unzip tests.zip
```

This should create a `tests/` directory with files like `test0.in` and `test0.out`.

### 2) Compile and run all tests

```bash
python3 run_tests.py --tests_dir ./tests
```

### 3) Run specific tests only (optional)

```bash
python3 run_tests.py --tests_dir ./tests --tests 0 10
```

### 4) Clean generated result files (optional)

```bash
python3 run_tests.py --tests_dir ./tests --clean
```

## Notes

- `run_tests.py` compiles all `.cpp` files in the selected code directory and creates `main.out`.
- Test outputs generated by your run are written as `test*.res`.
- If your output differs from the expected output, the test is marked as failed.
