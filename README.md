# DS_HW01

Data Structures Course - Homework Assignment 1

## Repository contents

- `README.md` - project overview and repository notes.
- `SegmentationResort26b1.h` - interface for the `SegmentationResort` class and required public API.
- `SegmentationResort26b1.cpp` - implementation template for the required `SegmentationResort` methods.
- `main26b1.cpp` - provided command-driven main program used to run and validate the implementation.
- `wet1util.h` - provided utility types (`StatusType`, `output_t`) used by the assignment API.
- `run_tests.py` - helper script that compiles all `.cpp` files and runs input/output tests.
- `dont_include.txt` - list of C++ standard library headers that are forbidden in this homework.
- `DS_wet1_spring_2026.pdf` - official homework specification document.
- `tests.zip` - bundled test input/output files for local validation.
